# Adding a taxonomy

Every bundled taxonomy is the same shape and arrives the same way. CSO and BIAN (2026-08-18) are the worked examples; OLiA, FIBO, NIST CSF and arXiv are older ones.

## The invariants

- **Pinned source.** The extraction reads a revision that cannot move: a git commit (BIAN, FIBO, OLiA, NIST, arXiv) or, where the publisher states no revision, the archive itself pinned by digest (CSO). `PinnedSource` covers the one-file permalink case; `ContentDigest` pins a file set; `GitBlobId` pins one blob.
- **Acceptance, not trust.** Whatever is read — fetched or handed over with `-P<name>=<path>` — is accepted only if it digests to the recorded constant, and a test pins the refusal message. The extraction JVM has no network route in agent sessions, so the `-P` path is the one that runs here.
- **Byte reproducibility.** Running the extraction twice over the pinned source produces identical bytes. No `Date.now()`, no environment in the output.
- **Eight columns.** `concept, prefLabel, altLabel, broader, kind, module, definition, note` — rendered through `SkosTsv`, which sorts by concept and refuses embedded tabs and line breaks. A repeated property joins with `" | "`.
- **Provenance header.** The renderer writes it: what the taxonomy is, column semantics where they need saying, `Source:` with the pin, `Licence:` with attribution terms, and a `Generated by <Extraction>: N rows` line. `VocabularyProvenanceTest` fails the build without Source and Licence lines.

## The files, in order

1. **`lexicon-extraction`**: a concepts reader (`CsoConcepts`, `BianConcepts` are models), a `<Name>Tsv` renderer holding the header, and a `<Name>Extraction` holding one `extract` method. **It states none of the machinery itself**: a source that is one file is pinned by `PinnedSource`, a source that is a set of files by `PinnedSet`, the file it writes is written by `BundledResource`, and it carries no `main`. Tests for each: the parsing rules, the row shape, the refusal.
2. **An entry in `BundledExtractions`**, which routes the one `extract` task: a `BundledExtraction` naming the taxonomy, stating in prose what it reads, and calling the extraction with the sources it takes and the files it writes. A source the extraction downloads for itself is read through `StatedSources.orDownloaded`, which passes blank; one it reads off disk through `StatedSources.path`, which refuses blank and names the taxonomy and what was missing. Run it with `./gradlew extract -Ptaxonomy=<name> -Psource=<path[,path]>` — no new Gradle task is added.
3. **The TSV itself**, committed under `lexicon/src/main/resources/` — run the task and commit its output, never hand-edit it.
4. **A lexicon class** naming the resource (`CsoTopics`, `BianServiceDomains`, `OliaTerms` are models): `fromClasspath()` singleton over `SkosRows.in(RESOURCE)`. A term taxonomy implements `PublishedTerms`; a functional or subject taxonomy exposes `concepts()`. `BundledResourceReachabilityTest` fails if nothing reads the resource.
5. **If it is matched against declared names**: an engine `TermIndex` (`ComputingTerms` is the model) and an entry in `MatchedTaxonomies`, which is the one list of what every run matches. If it is prose, it is placement-read instead and nothing joins the enum.
6. **`NOTICE.md`**: a row in the bundled-data table, with the attribution the licence requires.
7. **README**: the four-readings table, the term-taxonomy table if matched, References.
8. **Regenerate the readings** in a follow-up commit touching no Java — a new matched taxonomy changes the export and the reports. `./gradlew read` for this tree, then `./gradlew evaluationRead -Dcs.evaluation.dir=~/evaluation` for the evaluation set. Its members are already cloned at their pinned commits, and a fetch does nothing where a tree is already pinned, so **never re-clone a member**.

## What decides matched against placement

`TaxonomyShape` reads it off the file: prose per concept means a distribution to place against (BIAN, NIST, arXiv); labels without prose mean terms to match (CSO, OLiA, FIBO). A source cannot be both at once.

## Licence gate

CC0, CC BY, Apache-2.0 and MIT have all been bundled, each with its terms in the header and NOTICE.md. CC BY-SA attaches share-alike to the derived file and is carried where the source demands it (Wiktionary). A source whose licence cannot be stated does not ship — the ACM CCS is the precedent that stayed out.
