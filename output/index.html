Self-reading

CodeSemantics

Two kinds of document sit in this folder and a reader cannot tell them apart by looking. The summary prints what the reading showed; everything under it prints what the reading measured. Each entry names the bar a row had to clear to be printed at all.

  1. Summary

    what the reading shows, in one page

    What it takes to be printed: every line cleared a bar; what did not is named and printed nowhere

  2. Themes — the chart

    what the repository is about, drawn

    What it takes to be printed: only topics that distinguish some part of it and that more than one word carries

  3. Themes — the detail

    the same reading with every scope, witness and site

    What it takes to be printed: the ranking is qualified; the scope tables print everything measured

  4. Subjects

    where the repository stands against 152 published subject areas

    What it takes to be printed: the nearest must beat the nearest a taxonomy of chance offers

  5. The taxonomy

    the published field as a tree, with what this repository writes lit inside it

    What it takes to be printed: every concept is drawn; a branch nothing was written under is closed, not hidden

  6. The evidence

    every concept this repository writes, with the names and the lines it wrote them at

    What it takes to be printed: a count is a claim until somebody can go and look; this is what it links to

  7. Terms

    which branches of the field the repository occupies, and what it wrote there

    What it takes to be printed: a branch is ranked by distinct concepts written, not by how often

  8. Legibility

    how much of the repository any resource can be cited for

    What it takes to be printed: a denominator, not a finding

Regenerate all of it with./gradlew selfRead. Every figure is a reading of one commit of one working tree, and the corpus includes these reports.
